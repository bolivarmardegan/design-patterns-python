# Learning path

1. Read the introduction and understand the request/handler/chain roles.
2. Run the demo and step through `handle` using a debugger.
3. Change the order in `build_checkout_chain()`.
4. Add another handler and tests for both acceptance and rejection paths.
5. Compare the Python implementation with the Java implementation.
